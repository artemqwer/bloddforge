# Збірка застосунку через EAS (встановлення на айфон без 7-денного ліміту)

Expo Go зручний для розробки, але має обмеження: сесія живе 7 днів, нема пушів,
скло iOS 26 несправжнє. **EAS Build** збирає справжній нативний `.ipa` у хмарі
Expo (Mac не потрібен) — його встановлюєш на айфон і користуєшся постійно.

## Як це працює (коротко)

1. Твій код лишається тут, у репозиторії.
2. `eas build` пакує його й відправляє на **хмарні Mac-білдери Expo**.
3. Там з конфігу (`app.json` + `eas.json`) генерується нативний iOS-проєкт,
   компілюється і підписується твоїм сертифікатом Apple.
4. На виході — `.ipa`, який ти ставиш на айфон.
5. Дрібні зміни в JS потім можна надсилати **без перезбірки** через
   `eas update` (OTA) — застосунок підтягне їх при запуску.

## Що вже налаштовано в репозиторії

- `eas.json` — три профілі: `development`, `preview`, `production`.
- `app.json` — bundle id `com.ayugram.ios`, дозволи (фото, мікрофон),
  `runtimeVersion` для OTA-оновлень.
- `expo-updates` — для `eas update`.

## Що маєш зробити ти (одноразово)

Потрібні: безкоштовний акаунт **Expo** (expo.dev) і акаунт **Apple**.
Платний Apple Developer ($99/рік) бажаний, але для встановлення на свій
пристрій можна й безкоштовний (з лімітами).

```bash
# 1. Увійти в Expo
npx eas-cli login

# 2. Прив'язати проєкт (створить projectId у app.json)
npx eas-cli init

# 3. Зібрати версію для встановлення на свій айфон (ad-hoc)
npx eas-cli build --profile preview --platform ios
```

Під час першої збірки EAS спитає дані Apple і сам створить сертифікати та
provisioning profile. Твій айфон треба зареєструвати в профілі — EAS проведе
через це (`eas device:create`), або додай пристрій на developer.apple.com.

Коли збірка завершиться, EAS дасть **QR-код / посилання** — відкрий його на
айфоні й встанови `.ipa`.

## Профілі

| Профіль        | Для чого                                            | Команда |
|----------------|-----------------------------------------------------|---------|
| `development`  | Збірка з дев-інструментами (потрібен `expo-dev-client`) | `eas build --profile development --platform ios` |
| `preview`      | **Звичайне встановлення на свій айфон** (ad-hoc)     | `eas build --profile preview --platform ios` |
| `production`   | Для App Store / TestFlight                           | `eas build --profile production --platform ios` |

## OTA-оновлення (без перезбірки)

Після того як збірка стоїть на телефоні, зміни в коді надсилаються так:

```bash
npx eas-cli update --branch preview --message "опис змін"
```

Застосунок підтягне оновлення при наступному запуску. Працює лише для
JS/ресурсів; якщо додаєш новий нативний модуль — потрібна повна перезбірка.

## Важливо

- **Пуші** працюватимуть лише у власному білді (не в Expo Go) і потребують
  окремого налаштування `expo-notifications` + ключа APNs.
- Фічі невидимості порушують правила Telegram — ризик на твоєму акаунті.
- Збірку запускаєш **ти** зі свого акаунта: у цьому хмарному середовищі немає
  доступу до твого Expo/Apple логіну.
