# AyuGram iOS (Expo)

Неофіційний клієнт Telegram на Expo / React Native з фічами у стилі AyuGram:
невидимий режим і локальний архів видалених та відредагованих повідомлень.
Запускається в **Expo Go** — без Mac і без Xcode.

> ⚠️ Фічі невидимості порушують правила Telegram для сторонніх клієнтів.
> Використовуйте на власний акаунт і на власний ризик.

## Фічі

- **Невидимий режим**
  - не надсилати «прочитано» (чат читається вручну кнопкою 👁)
  - приховувати статус «онлайн»
  - не показувати «друкує…»
  - опція надсилати повідомлення відкладено, щоб не засвічувати «онлайн»
- **Архів**
  - збереження видалених повідомлень (підсвічуються в чаті + окремий журнал 🗑)
  - історія редагувань (утримати повідомлення → усі попередні версії)
- Список чатів, перегляд історії, надсилання тексту, фото у стрічці.

## Як запустити

1. Візьміть `api_id` та `api_hash` на <https://my.telegram.org/apps>.
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть дев-сервер:
   ```bash
   npx expo start
   ```
4. Відкрийте **Expo Go** на айфоні (App Store) і відскануйте QR-код.
5. У застосунку введіть `api_id` / `api_hash`, номер телефону і код із Telegram.

Сесія зберігається в захищеному сховищі (`expo-secure-store`), архів —
у локальній SQLite (`expo-sqlite`). Нічого не йде на жоден сервер, окрім
самого Telegram.

## Межі підходу

- Усе працює поверх [GramJS](https://github.com/gram-js/GramJS) (MTProto через
  WebSocket). Node-модулі, яких немає в Expo Go, замінені легкими shim-ами
  (`src/shims/`), криптографія — на чистому JS (`@noble/hashes`).
- Видалення/редагування ловляться, поки застосунок відкритий; при запуску
  дотягується пропущене через `updates.GetDifference` (приватні чати та групи).
- Пуш-сповіщень у Expo Go немає — потрібен власний dev/EAS build.

## Структура

```
src/
  app/            — екрани (Expo Router)
  tg/             — клієнт Telegram, налаштування, архів, історія
  shims/          — заглушки Node-модулів для Metro
  ui/             — тема та спільні компоненти
  polyfills.ts    — Buffer / crypto / window перед імпортом GramJS
```
